# قاضي اراك | Qadi Araak

منصة الإدارة القانونية الداخلية لمجموعة اراك للتنمية، وتخدم دورة العمل القانونية من الوقاية ومراجعة العقود والسياسات إلى إدارة الملفات اليومية والتحصيل والتنفيذ والإغلاق والتعلّم المؤسسي.

## نطاق المشروع

- مشروع داخلي مستقل خاص بمجموعة اراك للتنمية.
- لا يعتمد في هويته أو محتواه أو تشغيله على أي منتج أو علامة خارجية.
- المخرجات التقنية المساعدة لا تحل محل المراجعة والاعتماد المهني للمختص القانوني.
- تُحدَّد الصلاحيات بحسب الدور والجهة والحاجة إلى المعرفة.

## المتطلبات

- Node.js 20 أو أحدث
- npm 10 أو أحدث

## التشغيل المحلي

```bash
npm ci
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية، وغالباً:

```text
http://localhost:5173
```

## أوامر المشروع

```bash
npm run dev        # تشغيل بيئة التطوير
npm run typecheck  # فحص TypeScript
npm run build      # إنشاء نسخة الإنتاج داخل dist
npm run preview    # معاينة نسخة الإنتاج
```

## البناء والتحقق

يتم فحص TypeScript وبناء نسخة الإنتاج تلقائياً عبر GitHub Actions عند كل رفع إلى الفرع `main` وعند فتح طلبات الدمج.
